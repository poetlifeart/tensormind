rnetcarto

Fast network modularity and roles computation by simulated annealing (rgraph C library wrapper for R).

Example

> library(rnetcarto)

> # A general network.
> library(igraphdata,igraph)
> data(karate)
> web = get.adjacency(karate,sparse=FALSE)
> netcarto(web)
