METRIC CHECKS — each metric of the papers, isolated into its own self-contained
file and run on a published graph whose value for that metric is known.
Folder: graphnets/graphmetrics/onebyone/   (started 2026-10-28)

How each check is done
  1. ISOLATE   copy the metric's code from the script that produced the paper's
               number into one runnable file.  Copied functions are unchanged:
               check_same_code.py compares each one with the source (AST,
               docstrings/comments ignored).
  2. SAME      run the original script and the standalone on the same graph;
               the metric's numbers must be identical.
  3. REFERENCE find a graph online whose value for this metric is published,
               read the value in the publication itself, run the standalone on
               that graph, compare.  If no published value exists, SKIPPED (with
               what was searched).
  Reference graphs, with the raw downloads, are in reference_graphs/.
  newman_gml_to_npz.py converts Newman-format GML to the edge-list .npz the
  loader reads (undirected, unweighted, no self-loops, largest component).

PROBLEMS FOUND IN THE SOURCE SCRIPTS  (none changed; details in each entry)
  a. fractal_scaling (11): box size labelled l_B = 2 r_B; Song's convention is
     2 r_B + 1.  Box counts are exact, but any d_B printed is ~16% low (E. coli
     2.87; 3.42 with 2 r_B + 1; published 3.5).  Verdict unaffected.
  b. skeleton_fractality.py (16): its random-order ball cover needs 2-6x more
     boxes than MEMB and calls the E. coli network and its skeleton
     "exponential", where the literature reports fractal (d_B 3.5).
  c. modularity (4): Q is one Louvain run at seed 42; on karate that seed is the
     worst of 1,000 (0.385 vs optimum 0.42).  The modularity code itself is exact.
  d. Kirchhoff index (20): finite on a disconnected graph (should be infinite).
     Paper graphs are connected — unaffected.
  e. spanning-tree entropy (27): wrong for n > 2000 (sums 500 eigenvalues) and
     for disconnected graphs.  The papers report it only for 1,015-node
     connected graphs — unaffected.
  f. clique census (23): a null that hits its timeout adds a partial omega
     without a flag.  Did not happen on any graph checked.
  g. betweenness (14): 200 sampled sources whenever n > 200, i.e. on every
     paper graph — an estimate, not exact.
  h. rich-club floor (15): the 20-node floor removes any rich club smaller than
     20 nodes (by design; 2% of a 1,015-node graph).
  i. Comments only: connector-hub comment says "z > 2.5 AND P > 0.3" (code is
     z >= 2.5, 0.30 < P <= 0.75, the Guimera-Amaral rule); vertex-cover
     docstring says "greedy matching" (networkx uses local-ratio).
